# 🌌 Memory Galaxy — Match the Stars

A fun and interactive memory matching game built with **HTML, CSS, and JavaScript**. Test your memory, find matching pairs, and progress through increasingly challenging levels in a beautiful galaxy-themed world.

## ✨ Features

- 🃏 **Memory Matching:** Flip cards and find matching pairs.
- 👀 **Preview Mode:** Memorize all cards before the game begins.
- ⏱️ **Countdown Timer:** Complete each level before time runs out.
- ❤️ **Lives System:** Start with three lives; lose one for each incorrect match.
- 🚀 **Progressive Levels:** Play Easy, Medium, Hard, Expert, and Master.
- 🎨 **Multiple Themes:** Choose Animals, Fruits, Space, or Nature.
- 🏆 **High Scores:** Save your best results using browser local storage.
- 🔊 **Sound Effects:** Toggle game sounds on or off.
- 📱 **Responsive Design:** Enjoy the game on different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🎮 How to Play

1. Start a game and memorize the cards during the 3-second preview.
2. Click a card to reveal its symbol.
3. Click another card to find its matching pair.
4. Correct matches earn points.
5. Incorrect matches cost one life.
6. Find all pairs before the countdown reaches zero.
7. Complete a level and challenge yourself with the next difficulty.
